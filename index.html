SOBRE ESTE PROYECTO

Este portafolio es un proyecto de desarrollo web enfocado en la estructura semántica de HTML5, estilizado profesional mediante CSS y la integración de componentes interactivos y dinámicos en JavaScript.

Diseñado con una estética neo-brutalista de alto contraste que combina funcionalidad, alto rendimiento y una presencia visual limpia y vanguardista.

ÁREAS DE DESARROLLO

1. Maquetación HTML5

Estructuración semántica, jerarquía limpia de contenidos y buenas prácticas de accesibilidad.

2. Estilos CSS3 Modernos

Diseño con Flexbox, CSS Grid, variables CSS, micro-interacciones y maquetación 100% responsiva.

3. JavaScript Interactivo

Manipulación avanzada del DOM, eventos de usuario, validaciones y carga interactiva de archivos.

4. Optimización y Pruebas

Corrección de detalles visuales, pruebas en diferentes dispositivos y validación de sintaxis web.
